<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI-аргументы → файловая система и SQL | `--dir`, имена файлов и содержимое `.sql` приходят извне процесса |
| runner → PostgreSQL | DDL и advisory lock выполняются с полными правами |
| два runner-процесса | Конкурируют за одну схему |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-02 | Tampering | `preflight`, `validateDir`, имя файла в сообщении об ошибке | high | mitigate | Строгая грамматика `^V[0-9]{3,}__[a-z0-9_]+\.sql$`; canonicalize + проверка границы сегмента; имя файла никогда не конкатенируется в SQL |
| T-01-03 | Denial of Service | advisory lock | medium | mitigate | Только `pg_try_advisory_lock`; отказ немедленный; lock снимается в `finally`; тест с двумя соединениями |
| T-01-04 | Tampering | транзакция на файл + ledger | high | mitigate | `TransactionPerStep`; строка ledger пишется в транзакции файла; тест на откат при синтаксической ошибке |
| T-01-SC | Tampering | три новых Hackage-пакета | medium | mitigate | Все три в LTS 22.21; версии ограничены диапазонами; Package Legitimacy Audit в research не содержит [SUS]/[SLOP]; `postgresql-migration` помечен «verify» только по числу загрузок, не по легитимности |
</threat_model>
