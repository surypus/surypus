\chapter{Surypus ERP API
Documentation}\label{surypus-erp-api-documentation}

\section{Overview}\label{overview}

The Surypus ERP system provides a RESTful API for managing accounting,
inventory, tax, and reports. The API is built using Scotty and provides
endpoints for core ERP functionality.

\section{Base URL}\label{base-url}

\begin{verbatim}
http://localhost:8080
\end{verbatim}

\section{Authentication}\label{authentication}

The API uses JWT-based authentication. Include the JWT token in the
\texttt{Authorization} header:

\begin{verbatim}
Authorization: Bearer <token>
\end{verbatim}
