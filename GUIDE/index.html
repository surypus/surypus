Руководство администратора и пользователя

Раздел для администраторов системы (настройка, RBAC, backup) и конечных пользователей (бухгалтеры, менеджеры, логисты).

Часть 1: Руководство администратора

1.1. Управление пользователями и RBAC

Роли

Роль Уровень Типичный пользователь
Admin Полный доступ Владелец, IT-администратор
Manager Управленческий Директор, руководитель отдела
User Операционный Бухгалтер, менеджер, кладовщик
Viewer Только чтение Аудитор, внешний консультант

Право Admin Manager User Viewer

Полный список: RBAC.md (корень проекта).

Управление через API

── Создание пользователя
curl -X POST https://host/api/v1/register \
  -H "Content-Type: application/json" \
  -d '{"username":"ivanov","password":"securepass","role":"user","tenantId":1}'

── Список пользователей
curl https://host/api/v1/users \
  -H "Authorization: Bearer <admin-token>"

Аутентификация (JWT)

  • Токен выдаётся на 24 часа
  • Хранится в localStorage веб-клиента
  • Автоматический redirect на /login при 401
  • Password hashing: SHA256 (cryptonite)

1.2. Tenant management (Мультиарендность)

Создание организации

── API
curl -X POST https://host/api/v1/tenants \
  -H "Authorization: Bearer <admin-token>" \
  -d '{"name":"ООО Новая","slug":"novaya"}'

Переключение между тенантами

  • Веб-интерфейс: выпадающий список в хедере
  • Текущий tenant сохраняется в localStorage
  • JWT содержит tenant_id для изоляции данных
  • Все запросы фильтруются по tenant контексту

1.3. Резервное копирование

── Ежедневный бекап (cron)
0 2 * * * /usr/local/bin/backup-surypus.sh

── backup-surypus.sh:
pg_dump -h localhost -U surypus --format=custom \
  -f /backups/surypus_$(date +\%Y\%m\%d).dump surypus
pg_dump -h localhost -U surypus --format=plain \
  --schema-only -f /backups/surypus_schema.sql surypus
find /backups -name "*.dump" -mtime +30 -delete

Восстановление из бекапа

── Полное восстановление
pg_restore -h localhost -U surypus --dbname=surypus \
  /backups/surypus_20240315.dump

── Восстановление с пересозданием БД
dropdb -U surypus surypus
createdb -U surypus surypus
pg_restore -U surypus --dbname=surypus /backups/surypus_20240315.dump

1.4. Запуск и остановка

Часть 2: Руководство пользователя

2.1. Для бухгалтера

Типовые сценарии

Сценарий 1: Создание счёта на продажу

  1. Открыть раздел "Счета" → "Создать"
  2. Выбрать тип: "Продажа"
  3. Выбрать контрагента
  4. Добавить позиции (товар, количество, цена)
  5. Проверить сумму и НДС
  6. Сохранить как черновик
  7. Проверить данные → "Провести"

После проведения: - Товары списаны со склада по FIFO - Сгенерированы проводки (Дт 62 — Кт 90, Дт 90 — Кт 68/НДС, Дт 90 — Кт 41) - Остатки обновлены - Событие зафиксировано в EventStore

Сценарий 2: Формирование отчёта

  1. "Отчёты" → "Прибыли и убытки"
  2. Выбрать период (например, январь-март 2024)
  3. Формат: PDF
  4. Сгенерировать → Скачать

Сценарий 3: Просмотр оборотов

  1. "Бухгалтерия" → "Оборотно-сальдовая ведомость"
  2. Выбрать период
  3. Просмотреть обороты по счетам

2.2. Для менеджера по продажам

Типовые сценарии

Сценарий 1: Создание заказа

  1. "Заказы" → "Создать"
  2. Выбрать клиента (из справочника контрагентов)
  3. Добавить товары
  4. Указать цены и скидки
  5. Отправить на согласование

Сценарий 2: Работа с CRM

  1. "CRM" → "Сделки"
  2. Создать новую сделку (название, контакт, сумма, этап)
  3. Перемещать по этапам воронки: - Квалификация → Переговоры → Контракт → Закрыто
  4. Смотреть прогноз по воронке

Сценарий 3: Просмотр Dashboard

  1. "Главная" → Дашборд
  2. Видеть: - Выручку сегодня/неделя/месяц - Количество новых заказов - Просроченные задачи - Популярные товары

2.3. Для логиста / кладовщика

Типовые сценарии

Сценарий 1: Приём товара

  1. "Склад" → "Приход"
  2. Выбрать поставщика
  3. Выбрать товары (по накладной)
  4. Указать партии (дата, срок годности, серийные номера)
  5. Провести → товар оприходован, созданы партии

Сценарий 2: Проверка остатков

  1. "Склад" → "Остатки"
  2. Выбрать склад
  3. Просмотреть текущие остатки по товарам
  4. При необходимости — зарезервировать

Сценарий 3: Просмотр партий (FIFO)

  1. "Склад" → "Партии"
  2. Выбрать товар
  3. Увидеть: - Какие партии есть на складе - Остаток каждой партии - Себестоимость и цену - Срок годности

2.4. Для HR / расчётчика зарплаты

Типовые сценарии

Сценарий 1: Начисление зарплаты

  1. "Зарплата" → "Начисления"
  2. Выбрать сотрудника
  3. Указать период и сумму
  4. Провести

Сценарий 2: Просмотр истории

  1. "Зарплата" → "Сотрудники"
  2. Выбрать сотрудника
  3. Просмотреть все начисления за период

2.5. Веб-интерфейс (краткая справка)

Основные разделы

Раздел Назначение
Главная Dashboard: сводка по системе
Счета Создание и проведение счетов/накладных
Товары Справочник номенклатуры
Склад Остатки, партии, склады
Контрагенты Клиенты и поставщики
Бухгалтерия Проводки, обороты, баланс

Отчёты P&L, Inventory, экспорт

Навигация

  • Хедер: название компании (текущий tenant), меню пользователя
  • Переключение tenant: выпадающий список в хедере
  • Аутентификация: логин/пароль, JWT в localStorage
  • Регистрация: доступна через форму Register

2.6. Часто задаваемые вопросы (FAQ)

Q: Как восстановить забытый пароль? A: Через администратора системы (текущая версия не поддерживает self-service reset).

Q: Можно ли отменить проведённый счёт? A: Да, через аннулирование (статус CANCELLED). Остатки и проводки сторнируются.

Q: Как добавить нового сотрудника? A: "Контрагенты" → "Создать" (физ.лицо) → затем "Зарплата" → "Сотрудники" → привязать к контрагенту.

Q: Как выгрузить отчёт в Excel? A: Отчёты → Экспорт → выбрать формат (CSV, JSON). PDF-отчёты генерируются через weasyprint.

Q: Сколько пользователей может работать одновременно? A: Ограничений нет (пул соединений 50, масштабируется горизонтально).

2.7. Глоссарий

Термин Описание
Счёт Первичный документ (накладная, акт, счёт-фактура)
Проводка Бухгалтерская запись (Дт/Кт)
FIFO First In, First Out — метод списания себестоимости
Партия (Lot) Единица учёта товара с единой себестоимостью
Тенант (Tenant) Организация (юр.лицо) в мультиарендной системе
Проведение Фиксация документа в учёте (списание, проводки)
Остаток (Stock) Текущее количество товара на складе
Event Store Аппенд-только лог всех изменений
Классификатор Справочник (OKVED, OKPD2, ТН ВЭД и т.д.)
