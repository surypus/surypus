Surypus ERP

ERP/CRM система полного цикла на Haskell: формальная верификация, типобезопасный доступ к данным, event sourcing.

Раздел Описание
Архитектура Слои системы, схема данных, event sourcing
Система типов Типобезопасная модель предметной области
API REST API и его соглашения
Хранилище данных Схема PostgreSQL и миграции
