refreshAccessToken :: ConnectionPool -> JWTConfig -> Text -> IO (Either Text TokenPair) Source #

Validate a refresh token, rotate it (revoke the old one, store a new UUID), and issue a fresh access token. Proper rotation prevents refresh-token replay: a stolen token becomes useless after the first refresh, because the old token is deleted on rotation.
