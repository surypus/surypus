mkAccountingEventStore :: ConnectionPool -> Text -> IO AccountingEventStore Source #

Create a new accounting event store.

The Redis Stream is the fan-out path: when a server is reachable the store publishes every appended event to it. PostgreSQL stays the system of record, so a Redis outage degrades the store to "no stream" instead of failing.
