createWorkflowInstance :: WorkflowEngine -> Text -> Text -> IO Text Source #

Create a new workflow instance and register it in the engine.

The generated id is workflowId <> "-inst-" <> uuid so it is unique and traceable back to its workflow. Decisions pinned by WorkflowEngineSpec:

  • desc is not stored: WorkflowInstance carries no description field (a Workflow keeps its definition in the wfDefinition JSON text), so the argument cannot affect the instance — any value is accepted.
  • instanceSteps is always empty: nothing in the codebase registers workflows into engineWorkflows (there is no addWorkflow export and Workflow has no step list), so a step-less instance completes on its first executeWorkflowStep (advanceStep with current >= length steps).
  • WorkflowConfig (maxConcurrentInstances, defaultTimeoutSeconds, retryLimit) is not consulted: creation cannot fail (the return type has no error channel) and there is no timeout/retry state to configure.
