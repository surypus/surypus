Calculate line amount: qty * price - discount >= 0 Invariant: blAmount = max(0, blQty * blPrice - blDiscount)

Create accounting turn entries

Double-entry invariant: sum of Debit amounts = sum of Credit amounts - Debit = sum(lineAmount) - discount - Credit = total - Note: For simplicity, we assume debit = credit (no tax yet)

Emit a BillPosted domain event to the append-only event store. The event carries the bill aggregate id, the posted line totals, and a correlation id so the whole request can be traced end-to-end.
