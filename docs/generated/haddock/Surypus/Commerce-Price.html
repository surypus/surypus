applyDiscount :: Double -> Discount -> Double Source #

Get price with discount

The percentage branch is clamped at zero exactly like the absolute branch: a discount can never push a price below zero. The module's own validateDiscount rejects a percentage above 100, so clamping keeps the function total for callers that apply a Discount without validating it first (as calcFinalPrice does).

convertCurrency :: Double -> Double -> Double -> Double Source #

Convert price to different currency

A zero divisor is not a valid conversion: the caller has supplied a missing exchange rate, and dividing by it yields Infinity (or NaN when the numerator is zero too) — a silent, non-comparable result. The division is therefore guarded and a zero rate is reported instead.

priceWithoutVAT :: Double -> Double -> Double Source #

Get price without VAT

A rate of -100 makes the divisor zero, which yields Infinity for any positive price — a silent, non-comparable result. A rate that would divide by zero is rejected (the price is returned unchanged, which is what a zero-VAT document means) rather than propagating an infinite amount.
