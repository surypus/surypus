Description

Redis-backed read-model cache for account balances (US-3-3).

Core.Accounting.Cache covers the single-process case with an STM cache; this module is the Redis-backed variant, so a balance can be shared across processes and survive a restart. Every value is written with a TTL, so a stale balance can never outlive the configured window, and a Redis failure is never fatal - callers fall back to rebuilding from the event store.
