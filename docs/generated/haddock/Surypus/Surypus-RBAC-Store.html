data RBACStore Source #

RBAC Store

Carries the audit sink passed to newRBACStore so that writeAuditEntry can push every entry both into the in-memory log and to the external sink (logger / DB).

newRBACStore :: (AuditEntry -> IO ()) -> IO RBACStore Source #

Create a new RBAC store.

The audit callback is invoked synchronously by writeAuditEntry for every recorded entry, after the entry is appended to the log.

addGrant :: RBACStore -> PermissionGrant -> IO () Source #

Add a permission grant (prepended, so the newest grant is first)

removeGrant :: RBACStore -> Text -> Text -> PermissionGrant -> IO () Source #

Remove a permission grant.

Revokes exactly the passed grant: a stored grant survives unless its principal pair matches from/to AND it equals grant (same permission, scope and expiry). Revoking one grant of a pair must not silently revoke the other grants between the same principals.

cleanupExpiredGrants :: RBACStore -> UTCTime -> IO Int Source #

Cleanup expired grants.

A grant expiring exactly at now is still active and is kept (same boundary as activeDelegations). Returns the number removed.

activeDelegations :: RBACStore -> Maybe Text -> UTCTime -> IO [PermissionGrant] Source #

List active grants for a principal.

Nothing means "no principal filter": every active grant is returned. A grant is active when it has no expiry or its expiry is at or after now.

listAuditEntries :: RBACStore -> IO [AuditEntry] Source #

List audit entries (newest first)

cleanupAuditEntries :: RBACStore -> Maybe Int64 -> IO Int Source #

Cleanup audit entries (keep latest N, newest first). Default keep limit is 1000 when mKeep is Nothing. Returns the number removed.
