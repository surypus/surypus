lbCheck :: LeakyBucket -> IO Bool Source #

Check leaky bucket. An entry leaks out of the queue 'windowSize = 1/rate' seconds after it is added; the queue length is the number of entries that have not yet leaked. A request is admitted while the queue length is below capacity and is appended to the queue on success.
