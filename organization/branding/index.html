Surypus Branding Guidelines

This document describes the branding for Surypus.

Logo

The Surypus logo consists of:

  • Primary mark: A stylized "S" in a hexagon shape
  • Color: Deep blue (#2E5CB8)
  • Typography: Inter for body, JetBrains Mono for code

Color Palette

Color Hex Usage
Deep Blue #2E5CB8 Primary
Light Blue #78B7F0 Secondary
White #FFFFFF Background
Black #000000 Text
Gray #6B7280 Muted text

Typography

  • Headings: Inter (sans-serif)
  • Body: Inter (sans-serif)
  • Code: JetBrains Mono (monospace)
  • Newsreader for editorial content

Tone of Voice

Surypus communication is:

  • Friendly - Approachable, welcoming
  • Technical - Precise, well-documented
  • Inclusive - Respectful, accessible
  • Professional - Clear, direct

Taglines

  • "Formal verification for your ERP"
  • "Open source ERP/CRM with formal verification"
  • "Production-ready, type-safe, formally verified"

Naming Guidelines

General Principle

The name "Surypus" should be:

  • Memorable - Easy to remember and spell
  • Descriptive - Suggests purpose
  • Distinctive - Different from competitors

Usage in Text

  • First mention: "Surypus" (full name)
  • Subsequent mentions: "Surypus" or "the project"
  • In titles: "Surypus" (uppercase S)
  • In URLs: surypus (lowercase)

Do Not

  • Use "Surypus" as a verb
  • Use "Surypus" in all caps (except in logos)
  • Misspell "Surypus" as "Surypus" (common mistake)
  • Use "Surypus" in domain names without permission

Logo Usage

Approved Variations

  1. Full color: Blue logo on white background
  2. Monochrome: White logo on blue background
  3. Pictogram: Icon only without text

Minimum Size

  • Digital: 32px height
  • Print: 0.5 inches height

Clear Space

Maintain clear space equal to the height of the "S" around the logo.

Examples

Correct Usage

✅ "Surypus is an open source ERP/CRM system." ✅ "Get started with Surypus today." ✅ "Learn more at https://github.com/surypus/surypus"

Incorrect Usage

❌ "surypus" (should be capitalized) ❌ "Surypus's features" (should be "Surypus features") ❌ "surypus.svg" (file should be "Surypus.svg") ❌ "Surypus" in all caps
