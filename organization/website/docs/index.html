Surypus

Haskell ERP/CRM with Formal Verification

Welcome to the Surypus organization. We build production-ready Haskell systems with emphasis on formal verification, type safety, and software correctness.

Projects

Surypus ERP/CRM

Our flagship project — a distributed, type-safe accounting and event-sourcing core written in Haskell.

Key Features: - GHC 9.6.6+ with Stack - Persistent 2.18 + Esqueleto 3.6 for type-safe database access - LiquidHaskell for formal verification - Scotty for REST API - Event-sourced audit trail - RBAC permissions system
